Meridian record review update — based on b2b4f0a

1. Unzip this package. Open the Meridian GitHub repository, select the branch
   dropdown and create feature/record-review from the current main branch.
2. Confirm feature/record-review is selected. Use Add file > Upload files.
   Upload app.py, record_review.py and test_record_review.py into the repository
   root. If main has changed app.py since b2b4f0a, review and merge the edits
   instead of overwriting them. Do not upload this ZIP itself.
3. Commit to feature/record-review and open a draft pull request against main.
   Leave it unmerged until reviewed.

Tabs 3–6 have a Review a source record panel. Open exceptions hold combined
reporting and rollover exports and invalidate affected section acknowledgements.
The queue lives in the current Streamlit session; download JSON to keep a copy.
For corrections, have the data owner supply a revised workbook, then review it
again. The app never edits source records or grants funding, scope, or release approval.

Testing: four new tests pass, including a Streamlit reject-to-accept flow with
the bundled workbooks. Three pre-existing governance tests fail because their
fixture does not create the Backlog worksheet before accessing it.
